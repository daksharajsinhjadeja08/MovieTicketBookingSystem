## 📌 About the Project

The **Movie Ticket Booking System** is a web-based application developed using **ASP.NET Core MVC and C#**. It provides users with a convenient way to explore movies, check available theaters and show timings, and book movie tickets online.

This project was developed as a collaborative college project by a team of three members to understand real-world web application development using the .NET framework.

## ✨ Key Features

- 🏠 **Home Page** – Easy navigation to different sections of the application.
- 🎥 **Movie Listing** – Browse available movies and their details.
- 🏢 **Theater Information** – View available theaters and their locations.
- 🕒 **Show Timings** – Explore available shows and their timings.
- 🔍 **Movie-Based Show Selection** – View show timings based on the selected movie.
- 🎟️ **Ticket Booking** – Select a movie and show timing to book tickets.
- ✅ **Booking Confirmation** – Get confirmation after a successful booking.
- 📋 **Booking History** – View previously made bookings.
- 👥 **Customer Management** – Includes customer-related functionality.

## 🏗️ Project Architecture

The application follows the **MVC (Model-View-Controller)** architecture, helping organize the project into separate components.

| Folder | Description |
|---|---|
| 📁 Models | Contains application data classes. |
| 📁 Views | Contains the user interface pages. |
| 📁 Controllers | Handles user requests and application logic. |
| 📁 Interfaces | Defines interfaces used in the application. |
| 📁 Services | Contains service-related functionality. |
| 📁 Bookings | Contains booking-related components. |
| 📁 Exceptions | Contains custom exception handling components. |
| 📁 Properties | Contains project configuration settings. |
| 📁 Data | Contains application data files. |
| 📁 wwwroot | Stores static resources such as images and other frontend files. |

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### Prerequisites

- Visual Studio
- .NET SDK
- Git (optional, for cloning the repository)

### Installation

**1️⃣ Clone the repository**

```bash
git clone https://github.com/daksharajsinhjadeja08/MovieTicketBookingSystem.git
```

**2️⃣ Open the project**

Open the project folder in Visual Studio.

**3️⃣ Restore dependencies**

```bash
dotnet restore
```

**4️⃣ Run the application**

```bash
dotnet run
```

**5️⃣ Open the application**

Open the local URL displayed in the terminal in your web browser.
